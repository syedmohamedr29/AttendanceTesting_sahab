## 1. Covered Endpoints & Swagger DTO Hygiene Notes

| Endpoint | Purpose | Key Contract Observations |
| :--- | :--- | :--- |
| `POST /api/companies/{companyId}/workplans?locationId={locationId}` | Create Regular Work Plan | `locationId` optional in Swagger vs mandatory at runtime; `WorkPlanDto` wrongly exposes `id`, `isDeleted`, `tenantName` (`DEFECT-20261112-01/-02`). |
| `PATCH /api/companies/{companyId}/workplans/{id}?locationId={locationId}` | Update Regular Work Plan | `UpdateWorkPlanDto` wrongly exposes `isDeleted`, `tenantName`; partial `policyIds: []` skips clearing `Policies[]` (`DEFECT-20261112-05`). |
| `GET /api/companies/{companyId}/workplans/{id}` | Get Work Plan by ID | Leaks `200 OK` on soft-deleted, `Roster`, and `Rotation` plans (`DEFECT-20261112-11`). |
| `GET /api/companies/{companyId}/workplans/{id}/employees` | List Assigned Employees | Filters `segment`, `asOf`, `search`, `department`, `designation`, `page`, `pageSize`; returns copy-pasted `Cit.Attendance:1104` WorkTemplate error & silently clamps `page=0` (`DEFECT-20261112-12/-13`). |

### Recommended Clean Payload (`POST /workplans` & `PATCH /workplans/{id}`)
```json
{"workPlanName":{"en":"Sample Work Plan","ar":"خطة عمل نموذجية"},"description":"Work plan based on standard schedule with policies","isBreakPolicyEnabled":false,"isOvertimePolicyEnabled":false,"isGracePeriodPolicyEnabled":false,"policyIds":[],"workTemplateId":"1a80d87c-e37b-4d3d-bfc3-74ebed0dfbbb"}
```
> **Note:** Remove `id`, `isDeleted`, and `tenantName` from request DTOs (`DEFECT-20261112-01`, `-02`, `-07`).

## 3. UI Validation vs API Validation Separation

| Validation Concern | UI Validation Responsibility (Frontend) | API Validation Responsibility (Backend Must Enforce Independently) |
| :--- | :--- | :--- |
| **Form Field Validation (Inline)** | UI validates required Work Plan Name (EN), Description Min 10 chars, Work Template dropdown selection, and inline error banners before Submit. | API MUST independently enforce FluentValidation rules even when UI is bypassed via Postman/curl (currently bypassed on name.en, policy matrix, wrong types -> DEFECT-20261112-06/-09). |
| **Dropdown Scoping (Templates & Policies)** | UI dropdowns filter Active policies & Work Templates belonging to selected CompanyId/LocationId. | API MUST enforce CompanyId match, !IsDeleted, IsActive=true on referenced WorkTemplateId & PolicyIds (currently bypassed -> DEFECT-20261112-06/-09). |
| **Boolean Policy Toggles vs Selected IDs** | UI hides/clears selected policy selector when toggle is switched OFF, preventing mismatched flags and policyIds. | API MUST validate policyIds matches enabled boolean flags AND clear stale Policies[] when disabled on PATCH (currently fails -> DEFECT-20261112-05/-06). |
| **System-Derived Audit & Keys** | UI never lets user enter id, isDeleted, tenantName, createdAt, or createdBy. | API MUST NOT expose id, isDeleted, or tenantName in POST/PATCH request DTOs (currently exposed -> DEFECT-20261112-01/-02). |
| **Localization & Directionality (EN/AR)** | UI renders LTR/RTL layout, character counters, and Arabic font shaping. | API handles UTF-8 persistence, trimming, HTML/script sanitization checks, and independent EN/AR preservation during partial PATCH (currently AR wiped on EN-only PATCH -> DEFECT-20261112-09). |
